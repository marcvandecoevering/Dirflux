# Dirflux 0.1.0-beta.11

The default internal HTTP port is now **8080**, including the Docker image and Unraid template. Host ports remain freely configurable.

**Action required for existing containers:** change the container side of the port mapping from 8094 to 8080, keeping your host port unchanged. For example, use `8093:8080` to retain access at port 8093. Set Unraid WebUI to `http://[IP]:[PORT:8080]/`, and remove or update any explicit `PORT=8094` override. Custom `LISTENERS` override the default too. Apply the settings and update the image. Updating the image alone cannot change existing port mappings.

Accounts and files are preserved; retain both storage mounts. Native installations that do not set a port also move to 8080. See the [Unraid upgrade guide](../UNRAID.md#updates).
