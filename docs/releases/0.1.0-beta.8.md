# Dirflux 0.1.0-beta.8

The application interface is now consistently English: menus, dialogs, sharing, uploads, account management, accessibility labels, setup prompts and server error messages. Dates use English formatting, and generated file names use English defaults. Existing file names and contents are unchanged.

Update through Unraid using ghcr.io/marcvandecoevering/dirflux:beta, then reload the browser. No new settings or database changes are required.
