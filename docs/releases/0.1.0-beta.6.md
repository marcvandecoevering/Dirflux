# Dirflux 0.1.0-beta.6

Choose **Open in browser** or **Download directly** when creating a shared link. The choice is saved with the link and shown in the shared-links overview. Folders download as ZIP; unsupported formats still download, and active HTML/SVG content is served as plain text.

Copy Link now works on local HTTP connections using a clipboard fallback. If the browser blocks both methods, the link is selected for manual copying.

Existing links retain their previous behavior, including explicit download query parameters. Back up configuration before updating: this release adds a share-mode database column. A rollback to an older version requires its matching configuration backup.

Update through Unraid with ghcr.io/marcvandecoevering/dirflux:beta. Both container architectures and the native archive contain the same release.
