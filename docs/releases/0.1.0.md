# Dirflux 0.1.0

First stable release, graduating the working beta.11 application without a storage or account migration.

The standard Docker/Unraid channel is `ghcr.io/marcvandecoevering/dirflux:latest`, for AMD64 and ARM64. The old `beta` tag remains a compatibility alias. Daily verified security updates follow the stable channel.

Existing installations keep their files, settings and accounts. Installations older than beta.11 must update the internal port mapping to 8080 as described in the Unraid guide.
