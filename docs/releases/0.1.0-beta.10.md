# Dirflux 0.1.0-beta.10

API requests now bypass browser caches, preventing reuse of cached access-proxy login pages. Unexpected HTML responses produce a clear English message, including during uploads and session renewal. Failed requests are not automatically replayed.

HTTPS proxy checks cover login/logout, uploads, downloads, download/open share links and live updates. No database or configuration migration is required. Update the Unraid container using `ghcr.io/marcvandecoevering/dirflux:beta`, then hard-reload any existing browser tabs once.
