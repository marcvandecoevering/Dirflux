# Dirflux 0.1.1

Fix GHSA-g3hv-75wg-m249 (CVE-2026-118764) in the archive dependency chain by pinning readdir-glob's minimatch dependency to 11.0.3. Archiver remains on 8.0.0; no downgrade, audit suppression or reduced security checks are used.

The scoped override can be removed when readdir-glob requires a patched minimatch release itself. Its matching API and archive behavior are covered by regression and release tests.

Update Docker or Unraid through `ghcr.io/marcvandecoevering/dirflux:latest`. The legacy `beta` alias receives the same image. Files, accounts, settings and port mappings are unchanged from 0.1.0.
